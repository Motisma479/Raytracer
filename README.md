## ⭐ About the Project
This project started as a specialization project at school, where I had to choose a specialization for my final year at [ISART Digital](https://www.isart.fr/). I'm still working on it in my free time to improve my GPU programming skills.

The project is written in [![C++20](https://img.shields.io/badge/C%2B%2B-20-00589c?logo=C%2B%2B)](https://isocpp.org/) and built using [![CMake 3.10](https://img.shields.io/badge/CMake-3.10-004078?logo=cmake)](https://cmake.org/). For GPU programming, I use [![OpenCL](https://img.shields.io/badge/OpenCL-ee332d)](https://www.khronos.org/opencl/) to ensure compatibility across different GPUs.
